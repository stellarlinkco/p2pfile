这个重写强调什么

更少边框噪音 层次用背景、密度和对齐来表达，不用过多卡片嵌套。
01
更强结果态 completed / ended / occupied 各自有明确视觉身份。
02
更直的术语 Share Link、Access Code、Frozen Manifest、Transfer Mode 保留现有词汇。
03
Open file locally and inspect how the sender/receiver surfaces reflow on narrow widths and keep the same entry vocabulary.
